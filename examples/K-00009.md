SUPERSEDES K-00008 BECAUSE: at one frame per second the link fails its checksum on roughly a
third of frames (K-00005, measured), so the old rule bought smoothness by silently discarding
data — the opposite of what it was for.
RULE: poll the outdoor unit at the interval configured in the logger's settings file
(`poll_interval` in the logger configuration), and treat any change to it as a change that must
be measured: run the checksum counter for ten minutes before and after.
LIMITS: this is about the serial link, not about the unit's own sampling — the unit may internally
sample faster than it transmits, so a shorter poll interval never buys resolution the unit does
not have.
IMPLICATIONS: smoothness in the plot is a presentation problem, to be solved in the plot.
Interpolating in the summary job is acceptable only where the interpolation is visible as such.
